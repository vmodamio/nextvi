17. Added forced-linebreak markers using U+200B

- Implemented the requested forced-linebreak mechanism.
- Chose U+200B zero-width space as the marker.
- Added shared macros:
  `HWBRK`
  `HWBRK_LEN`
- Added U+200B to the placeholder table in `conf.c` with zero display width and empty display text.
- Live hard wrapping now prefixes automatically generated continuation lines with U+200B.
- The marker is stored in the file but rendered invisibly and without occupying a column.

18. Implemented paragraph reflow for forced-linebreak continuations

- Added detection for forced continuation lines:
  a line starting with U+200B is considered generated by the wrapping mechanism.
- When editing a line in a wrapped paragraph, the editor now:
  - finds the paragraph head,
  - absorbs following forced continuation lines,
  - removes the forced-linebreak markers,
  - joins the paragraph text logically,
  - rewraps it according to `conf_hwwidth`,
  - writes fresh U+200B markers on generated continuation lines,
  - stops at the next normal user-created line break.
- This means inserting text into a previous wrapped line reflows all following forced continuation lines until the next real line break.
- Fixed a crash in the live insert handler where it searched for the last newline in the temporary buffer instead of the newly inserted wrap newline.
- Verified that:
  - wrapped continuation lines are saved with U+200B bytes `e2 80 8b`,
  - U+200B is invisible in the editor,
  - editing the first line of a marked paragraph reflows the following marked lines,
  - the reflow stops at the next unmarked line.
- Committed as:
  `56eac55 Reflow forced hard wrap continuations`
